# 变更记录

**时间**: 2026-01-24 10:30:00
**目标**: 实现论文阅读页目录点击跳转功能，并优化目录显示（缩进）。
**变更范围**: 
- `main/frontend/src/app/reader/[id]/page.tsx`: 传递 `onNavigate` 回调给 `ReaderSidebar`，用于更新当前页码。
- `main/frontend/src/components/reader/ReaderSidebar.tsx`: 
    - 绑定点击事件触发 `onNavigate`。
    - 优化 TOC 渲染逻辑，根据 `level` 字段动态设置左边距以体现层级结构。
- `main/frontend/src/components/reader/PDFViewer.tsx`: 
    - 在 Scroll 模式下，为每个页面容器添加 ID (`page_{n}`)。
    - 添加 `useEffect` 监听页码变化，在 Scroll 模式下自动滚动到对应页面。

**验证方式**:
1. 代码逻辑检查: 确认 `ReaderPage` 接收页码更新并传递给 `PDFViewer`。
2. `PDFViewer` 响应: 确认 Pagination 模式下依赖 `react-pdf` 的 `pageNumber` 属性，Scroll 模式下依赖 `scrollIntoView`。
3. 样式检查: 确认 `ReaderSidebar` 使用 `paddingLeft` 实现缩进。

**结果**: 
- 用户点击左侧目录项时，PDF 阅读器会自动跳转到对应页面（支持翻页模式和滚动模式）。
- 目录结构显示更加清晰（有缩进）。
