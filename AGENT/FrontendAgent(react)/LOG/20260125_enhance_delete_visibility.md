# 变更日志: 增强删除功能可见性

**提交人**: FrontendAgent(react)
**日期**: 2026-01-25 21:58:00

## 变更目标
解决用户反馈的“无法清除标记”问题。实际上删除功能存在，但可能因为UI不够明显或操作路径不清晰导致用户无法找到。

## 变更内容

### 1. 增强编辑弹窗 (Edit Popup)
- **文件**: `src/components/reader/PDFPageOverlay.tsx`
- **修改**: 将原有的仅图标显示的删除按钮改为 **图标 + 文字 ("删除")** 的形式。
- **样式**: 使用红色背景/文字 (`bg-red-50 text-red-600`) 强化视觉提示，使其在弹窗中更显眼。

### 2. 增强备注 Tooltip (Note Tooltip)
- **文件**: `src/components/reader/PDFPageOverlay.tsx`
- **修改**: 在备注悬浮提示框 (Tooltip) 的头部添加了直接删除按钮。
- **逻辑**: 用户无需点击进入编辑模式，仅需悬浮查看备注时即可点击右上角的垃圾桶图标删除备注。这大大缩短了删除路径。

### 3. 增加交互提示
- **修改**: 为所有标注元素 (Highlight/Note) 添加了 HTML `title` 属性: `"点击编辑或删除"`。
- **目的**: 当用户鼠标悬停在高亮区域时，浏览器原生提示会告知用户该元素是可交互的。

## 验证方式
- 检查代码编译无误。
- 确认 `onDeleteAnnotation` 回调正确传递并绑定。
- 确认删除按钮的 `stopPropagation` 已添加，防止触发底层的点击事件。
