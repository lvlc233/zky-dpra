# 2026-01-25 Implement Note Edit Feature

## 目标
响应用户需求："我想点击编辑的时候原本下面的新建就变成修改,然后那里还有一个+号,可以切换为新建模式"。
1. 允许用户点击笔记列表中的编辑图标，将笔记内容加载到下方的编辑器中。
2. 编辑器状态切换为"编辑模式"，提交按钮变为"更新笔记"。
3. 在编辑模式下，标题旁显示一个"+"号（叉号旋转45度），点击可退出编辑模式，清空编辑器并恢复为"新建模式"。

## 变更范围
1. `src/components/reader/tabs/NotesTab.tsx`:
   - 新增状态 `editingNoteId` 用于追踪当前正在编辑的笔记 ID。
   - 重构 `handleAddNote` 为 `handleAddOrUpdateNote`，根据 `editingNoteId` 决定是调用创建接口还是更新接口。
   - 实现 `startEdit` 函数：设置 `editingNoteId` 并填充 `newNote` 内容。
   - 实现 `cancelEdit` 函数：重置 `editingNoteId` 和 `newNote`。
   - 更新 UI：
     - 笔记列表项的编辑按钮绑定 `startEdit`。
     - 编辑器标题栏根据模式显示"新建笔记"或"编辑笔记"，并按需显示取消编辑的"+"按钮。
     - 提交按钮根据模式显示不同颜色（新增为 indigo，更新为 emerald）和文字/图标。

## 验证方式
1. **新建测试**: 在未选中任何笔记时，输入内容点击"添加笔记"，确认笔记添加成功且列表更新。
2. **编辑模式进入**: 点击已有笔记右上角的铅笔图标。
   - 预期：下方输入框自动填入该笔记内容。
   - 预期：标题变为"编辑笔记"，旁边出现"+"号。
   - 预期：底部按钮变为绿色的"更新笔记"。
3. **更新测试**: 修改内容后点击"更新笔记"。
   - 预期：提示"笔记更新成功"，列表中的该条笔记内容更新，编辑器重置为新建模式。
4. **取消编辑**: 进入编辑模式后，点击标题旁的"+"号。
   - 预期：输入框清空，界面恢复为"新建笔记"模式。

## 结果
- 已完成代码修改。
- 实现了无缝的编辑/新建模式切换，提升了笔记管理体验。
