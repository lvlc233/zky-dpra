# 2026-01-25 笔记(Note)悬停显示备注功能优化

## 基本信息
- **时间**: 2026年01月25日 02:31
- **责任人**: FrontendAgent(react)
- **目标**: 优化 PDF 阅读器中笔记(Note)的交互体验，实现鼠标悬停时在上方显示备注内容，并确保多行标注时的定位准确性。

## 变更范围

### 1. 阅读器覆盖层 (PDFPageOverlay)
- **路径**: `src/components/reader/PDFPageOverlay.tsx`
- **变更**:
    - **定位优化**: 修改 `handleAnnotationMouseEnter`，使其接收当前悬停的具体矩形区域 (`rect`)，而非仅仅依赖标注的第一个区域。这确保了对于跨行或多段的笔记，提示框能准确显示在用户鼠标悬停的片段上方。
    - **防抖处理**: 在 `handleAnnotationMouseLeave` 中引入 100ms 的延时关闭机制 (`setTimeout`)，防止用户在同一标注的不同矩形区域间移动时提示框闪烁或意外消失。
    - **状态管理**: 引入 `hoverTimeoutRef` 来管理定时器，确保在快速交互时的状态正确性。

## 验证方式与结果
- **代码逻辑检查**:
    - 确认 `onMouseEnter` 正确传递了当前 `rect` 参数。
    - 确认 `onMouseLeave` 设置了延时清除状态。
    - 确认再次 `onMouseEnter` 会清除之前的延时定时器，保持提示框显示。
    - 确认提示框样式 (Tooltip) 设置了 `pointer-events-none`，不影响底层交互。
- **预期效果**:
    - 当鼠标悬停在红色虚线（笔记）上方时，会立即在上方显示包含备注内容的卡片。
    - 在多行笔记之间移动鼠标时，提示框位置会跟随当前行，且不会闪烁消失。
