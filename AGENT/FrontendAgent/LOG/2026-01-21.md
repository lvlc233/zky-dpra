
## 22:23 - 移除视图与报告概念

### 目标
响应用户需求，简化阅读器界面，移除“视图”和“报告”的概念，保留并在默认视图上直接支持“标记”功能。

### 变更范围
1.  **Reader Sidebar (左侧栏)**:
    *   `src/components/reader/ReaderSidebar.tsx`:
        *   移除 Tab 切换逻辑（视图/目录）。
        *   移除 `LayersView` 组件及相关依赖（图标、Props）。
        *   简化为仅展示 `OutlineView`（目录）。
2.  **Reader Right Panel (右侧栏)**:
    *   `src/components/reader/ReaderRightPanel.tsx`:
        *   移除 `ReportTab`（报告）及相关图标。
        *   更新 Tabs 列表，仅保留导读、笔记、脑图、设置。
3.  **Reader Page (主页面)**:
    *   `src/app/reader/[id]/page.tsx`:
        *   移除传递给 Sidebar 的视图管理相关 Props (`layers`, `activeViewId`, `onAddLayer` 等)。
        *   移除不再使用的视图管理 Handlers (`handleAddLayer`, `handleDeleteLayer`, `handleToggleLayerVisibility`, `handleSetActiveLayer`)。
        *   保留 `layers` 和 `activeViewId` 状态及初始化逻辑，确保 PDFViewer 能在默认（第一个）视图上正常加载和创建标注。

### 验证方式与结果
*   **代码逻辑**: 确认 Sidebar 不再渲染视图列表，RightPanel 不再渲染报告 Tab。
*   **预期效果**:
    *   进入阅读页，左侧仅显示目录，无视图切换入口。
    *   右侧无“报告”选项卡。
    *   标注功能通过默认选中的第一个视图（通常是“原文 (Base)”）正常工作，用户感知为“直接在论文上标记”。

## 23:07 - 重构设置模块 (Settings Refactor)

### 目标
根据最新的架构文档，重构全局设置模块，将其划分为系统设置、搜索设置和 AI 阅读助手设置三个部分。

### 变更范围
1.  **Type Definitions**:
    *   创建 `src/types/settings.d.ts`，定义 `SystemSettings`, `SearchSettings`, `AIReaderSettings` 等接口。
2.  **Service Layer**:
    *   创建 `src/services/settings.service.ts`，封装 API 请求 (`GET/PUT` for system/reader, `POST/PATCH` for search)。
3.  **UI Component**:
    *   重构 `src/components/settings/SettingsModal.tsx`:
        *   移除原有的 General/Account/Privacy/Data 结构。
        *   实现 **系统设置 (System)**: 深色模式切换。
        *   实现 **搜索设置 (Search)**: 最小/最大日期、Limit、分析状态配置。
        *   实现 **AI 阅读设置 (Reader)**: 支持 Chat (含向量搜索开关)、Summary、MindMap 三种 Agent 的独立配置 (Provider, Model, API Key, Base URL)。

### 验证方式与结果
*   **代码逻辑**: 确认 `SettingsModal` 正确调用 `settingsService` 加载和保存数据。
*   **UI 交互**: 确认 Tab 切换正常，表单状态管理独立，保存操作分别触发对应的 API。
*   **兼容性**: 保持了 `SettingsModal` 的 Props 接口 (`isOpen`, `onClose`) 不变，确保现有调用处 (`DashboardPage`) 无需修改。
